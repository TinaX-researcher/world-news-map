# World Macro & News Map

Click any country to see live news, FX rate (+ 90-day sparkline), policy rate, 10Y bond yield, benchmark equity index, and key sectors.

## Run

Just open `index.html` in a browser — no server needed.

## Refresh policy rates & bond yields

The macro snapshot ships with a curated 2026-05 baseline. To refresh it:

```bash
pip install -r requirements.txt
python3 update_data.py
```

This scrapes Wikipedia (policy rates) and worldgovernmentbonds.com (10Y yields), writes `data.js`, and the next time you open `index.html` the snapshot will show "live as of YYYY-MM-DD" in the footer.

Run weekly via cron:

```
0 9 * * 1  cd ~/Desktop/world-news-map && python3 update_data.py
```

## Data sources

- **FX rates**: [frankfurter.app](https://www.frankfurter.app/) — live, ECB-sourced, no key
- **News**: [GDELT 2.0 Doc API](https://www.gdeltproject.org/) — last 7 days, no key
- **Policy rates**: Wikipedia (refreshed by `update_data.py`)
- **10Y yields**: countryeconomy.com (refreshed by `update_data.py`)
- **YTD index returns**: Yahoo Finance unofficial chart API (refreshed by `update_data.py`)
- **Sectors / index names**: curated, edit `COUNTRY_DATA` in `index.html`
- **Map**: Leaflet + [johan/world.geo.json](https://github.com/johan/world.geo.json)

## Files

- `index.html` — the page (open this)
- `update_data.py` — refresh script
- `requirements.txt` — Python deps
- `data.js` — generated by `update_data.py`, optional; merged in at runtime if present
